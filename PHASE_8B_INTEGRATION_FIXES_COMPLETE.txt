## PROBLEM 1: Home Page Not Showing Service Centres
Status: ✅ FIXED

Root Cause:
- HomeScreen was using vehicleViewModel.serviceCentresState
- But service centres were never populated there
- The actual data was in DiagnosticsViewModel.backendResponse

Fix Applied:
- Updated HomeScreen to derive serviceCentresState from 
  backendResponse.serviceCentres
- Convert ServiceCentreDto to ServiceCentre model
- Pass the converted state to NearbyServiceCentresCard
- Service centres now display immediately after vehicle check

Impact:
- Home now shows same service centres as Diagnose screen
- No separate service-centre API call needed
- Shared state across screens working correctly

Status: ✅ FIXED

Root Cause:

  - Background → MaterialTheme.colorScheme.background

  - Surfaces → MaterialTheme.colorScheme.onSurface

  - Header text color → MaterialTheme.colorScheme.onBackground
  - Header icon tint → MaterialTheme.colorScheme.onBackground
  - Bottom bar background → MaterialTheme.colorScheme.surface
  - Bottom bar text/icons → MaterialTheme theme colors

- Updated NotificationsScreen
  - TopAppBar colors → MaterialTheme.colorScheme.background
  - Text colors → MaterialTheme.colorScheme.onBackground

- ChatScreen already using MaterialTheme colors (verified)

Impact:
- Theme switching now works: Light/Dark/System respects selection
- Root-level AutoRescueTheme(themeMode) applies to entire app
- All new screens automatically theme-aware via MaterialTheme
